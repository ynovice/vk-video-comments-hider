# VK Video Comments Hider

Расширение для Firefox, которое позволяет скрывать комментарии под видео на **vkvideo.ru**. Скрывать - раскрывать комментарии можно тумблером в попапе расширения.

## Установка

Расширение не опубликовано в магазине дополнений Firefox, поэтому ставится вручную.
Это пара шагов, но каждый раз после перезапуска браузера их придётся повторять — так
работает временная установка.

1. Скачайте репозиторий: зелёная кнопка **Code** → **Download ZIP**, и распакуйте архив.
2. Откройте в Firefox адрес `about:debugging#/runtime/this-firefox`.
3. Нажмите **«Загрузить временное дополнение…»**.
4. Укажите файл `manifest.json` из распакованной папки.

Расширение сразу появится на панели инструментов.

> Временное дополнение Firefox сбрасывает при перезапуске. После закрытия браузера
> повторите шаги 2–4.

## Требования

Firefox 140 или новее.
